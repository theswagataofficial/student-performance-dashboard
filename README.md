# Student Performance and Study-Hours Dashboard

A simple Python project using anonymised sample data.

## Files
- `dashboard.py` — main Python program
- `students.csv` — sample dataset
- `requirements.txt` — required libraries

## Install
```bash
pip install -r requirements.txt
```

## Run
Keep `dashboard.py` and `students.csv` in the same folder, then run:
```bash
python dashboard.py
```

The program prints score statistics, grades, course averages, and correlation values.
It also creates `study_hours_vs_score.png` and `score_histogram.png`.

**Note:** This is sample data for educational use. Correlation does not prove that
studying more causes higher scores.
